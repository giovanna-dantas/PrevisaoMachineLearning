# Previsão de Score de Clientes com Machine Learning

## Descrição

Este projeto tem como objetivo construir um **modelo de Machine Learning capaz de prever o score de crédito de clientes de um banco**.

A partir de uma base de dados contendo informações sobre **100.000 clientes**, foram realizadas etapas de **tratamento de dados, análise exploratória e treinamento de modelos de classificação**, com o objetivo de identificar se um cliente possui **bom score ou não**.

Esse tipo de modelo é extremamente importante para instituições financeiras, pois auxilia na tomada de decisões relacionadas a:

- concessão de crédito
- empréstimos
- definição de limites
- análise de risco de inadimplência

---

## Tecnologias utilizadas

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook
- Numpy

---

## Objetivo do projeto

Criar um modelo capaz de prever se um cliente possui um **bom score de crédito**, utilizando algoritmos de **Machine Learning supervisionado**.

---

## Etapas do projeto

O projeto foi desenvolvido seguindo as seguintes etapas:

### 1. Importação da base de dados

Carregamento da base contendo informações dos clientes.

---

### 2. Análise inicial dos dados

- Verificação de dados ausentes
- Identificação de tipos de variáveis
- Inspeção geral da base de dados

---

### 3. Tratamento dos dados

- Conversão de variáveis categóricas
- Tratamento de valores nulos
- Preparação da base para o treinamento dos modelos

---

### 4. Seleção das variáveis

Definição das colunas que serão utilizadas como **features** para o modelo de Machine Learning.

---

### 5. Treinamento dos modelos

Foram utilizados dois algoritmos de classificação:

- Random Forest
- Árvore de Decisão

Esses modelos foram treinados para prever o **score de crédito dos clientes**.

---

### 6. Avaliação dos modelos

Após o treinamento, os modelos foram avaliados para identificar qual deles apresenta **melhor desempenho na previsão**.

---

### 7. Análise das variáveis mais importantes

Foi realizada uma análise para identificar **quais características dos clientes mais influenciam na definição do score**.

Isso permite entender melhor os fatores que impactam na análise de crédito.

---

## Importância do projeto

Projetos como este são amplamente utilizados no setor financeiro para:

- análise de risco de crédito
- prevenção de inadimplência
- definição de limites de crédito
- apoio à tomada de decisão
